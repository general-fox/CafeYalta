# Локальные шрифты

Стили подключаются через `public/assets/fonts/fonts.css`. В HTML Vite можно добавить `<link rel="stylesheet" href="%BASE_URL%assets/fonts/fonts.css">`, чтобы сохранить поддержку подпапки GitHub Pages. URL внутри CSS относительные.

- **Manrope**: normal, переменная насыщенность 200–800, кириллица и латиница.
- **Cormorant Garamond**: normal и italic, переменная насыщенность 300–700, кириллица и латиница.
- `font-display: swap` позволяет показывать текст сразу.
- Шесть файлов WOFF2, суммарно около 155 КБ. Шрифты не требуют внешних запросов после размещения сайта.

Загружено 7 ноября 2026 года из Google Fonts CSS API:
https://fonts.googleapis.com/css2?family=Manrope:wght@200..800&family=Cormorant+Garamond:ital,wght@0,300..700;1,300..700&display=swap

Файлы предоставлены fonts.gstatic.com. Для шрифтов действует SIL Open Font License 1.1. Тексты лицензий сохранены рядом с файлами как `Manrope-OFL.txt` и `CormorantGaramond-OFL.txt`; источники:

- https://github.com/google/fonts/tree/main/ofl/manrope
- https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
